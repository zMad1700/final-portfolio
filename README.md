# Kenneth Jorolan — Portfolio

A personal portfolio for Kenneth Lance Jorolan, a developer based in Digos City, Davao del Sur. The site introduces Kenneth, shares his current learning path, and provides a foundation for publishing project work.

## Tech stack

- Vue 3 and Vite
- Vuetify
- Vue Router
- GSAP with ScrollTrigger
- Laravel API (backend)
- PostgreSQL (database)

## Run the frontend

```sh
npm install
npm run dev
```

Vite prints the local URL in the terminal. Create a production bundle with `npm run build`.

## Backend

The Laravel API setup is in the `backend` directory. See [backend/README.md](backend/README.md) for database configuration and local startup.
